# 七彩 (Nanairo) — 画像ライブラリマネージャー

生成したAI画像が、そのままプロンプトの資産になるローカル完結型の画像管理ツールです。

- 公式サイト（試用版の入手）: https://rikka-novel.com/nanairo/
- 製品版のご購入（note）: https://note.com/nonb0716/n/n17e8939984ec

## 主な特徴
- キャラクター・シーンごとの画像整理
- プロンプトの部品化・再利用
- 投稿前のモザイク加工機能（7段階）
- 完全ローカル動作（外部通信なし・画像非コピー）
